# Manus and open-source agent platforms: a FAQ

Kortix is the open-source AI Operating System, and these are the questions a team asks when it searches for a Manus alternative. Each answer states the fact and names the source.

## Is Manus open source?

No. Manus is a hosted, closed agent. You sign in, the work runs in Manus's product, and its page publishes no source repository and no self-host path ([Manus](https://manus.im), checked October 2026). Kortix is the open-source AI Operating System. Read it, fork it, audit it. You run it on Kortix Cloud, in your VPC, or on your own on-prem network, and self-host is free.

## What is a free AI agent similar to Manus AI?

Kortix is the free, open-source agent platform closest to what a team wants from Manus. The Free plan is $0 with 200 credits per month and 1 project, and self-hosting the full stack is free ([Kortix pricing](https://kortix.com/pricing), checked October 2026). You get agents, skills, company memory, and connectors in one git repo you own, any model with your own keys, and one isolated sandbox per session.

## Can you self-host an agent platform like Manus?

Manus itself is hosted only, with no self-host path on its product page. You can self-host Kortix, the open-source AI Operating System. One command installs a Docker Compose stack of the same images the managed cloud runs, with your database and files on disk you control ([Self-hosting](https://kortix.com/docs/host)). The requirements are a Linux server with a public IP, DNS, ports 80 and 443, and a sandbox provider key.

## Where do I start?

Clone this repository, run `kortix ship`, and ask the research agent for a brief. [Try Kortix](https://kortix.com) for the managed cloud, or read [Open-source Manus alternatives](https://kortix.com/blog/open-source-manus-alternatives) for the wider open-source field.
